# Киновечер

Общий список фильмов и сериалов на двоих: поиск по базе TMDB с постерами, очередь «к просмотру», оценки от 1 до 10 у каждого свои, случайный выбор «Что смотрим?».

Вход без регистрации: один создаёт комнату, второму отправляет ссылку или 6-значный код.

## Что внутри

```
public/          интерфейс (HTML, CSS, JS без сборки)
api/search.js    поиск в TMDB
api/img.js       постеры через свой домен (грузятся, даже если image.tmdb.org недоступен)
api/rooms.js     создание комнаты
api/room.js      содержимое комнаты и действия: войти, добавить, отметить, удалить, оценить
lib/             работа с TMDB и базой
dev.js           локальный запуск
```

Хостинг: Vercel (бесплатный тариф Hobby). База: Upstash Redis через Vercel (бесплатный тариф). Ключ TMDB хранится только на сервере.

## Как выложить (примерно 10 минут)

### 1. Ключ TMDB

1. Зарегистрируйтесь на https://www.themoviedb.org/signup и подтвердите почту.
2. Откройте **Settings → API** (https://www.themoviedb.org/settings/api) и запросите ключ: тип **Developer**, использование личное. В анкете хватит короткого описания вроде «personal watchlist app».
3. Скопируйте **API Read Access Token** — длинную строку, которая начинается с `eyJ`.

### 2. Проект на Vercel

Вариант через GitHub (удобно обновлять):

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. На https://vercel.com войдите через GitHub → **Add New → Project** → выберите репозиторий.
3. Framework Preset: **Other**. Остальное не трогайте → **Deploy**.

Вариант без GitHub: в этой папке выполните `npx vercel` и ответьте на вопросы (настройки по умолчанию подходят).

### 3. База данных

1. В проекте на Vercel откройте вкладку **Storage → Create Database**.
2. Выберите **Upstash → Redis**, бесплатный план, регион поближе (например Frankfurt).
3. Подключите базу к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.

### 4. Ключ TMDB в настройках

**Settings → Environment Variables** → добавьте:

| Name | Value |
|---|---|
| `TMDB_TOKEN` | ваш API Read Access Token |

Если удобнее короткий API Key, назовите переменную `TMDB_API_KEY`.

### 5. Перевыкладка

**Deployments** → у последней выкладки меню «⋯» → **Redeploy**. Переменные подхватываются только при новой выкладке.

Готово. Откройте адрес вида `https://ваш-проект.vercel.app`, создайте комнату и нажмите на код комнаты, чтобы скопировать ссылку для друга.

## Локальный запуск

```bash
npm install
TMDB_TOKEN=eyJ... node dev.js
# http://localhost:3000
```

Без переменных Upstash данные хранятся в памяти и пропадают после перезапуска.

## Если что-то не работает

- **«Не задан ключ TMDB»** или **«TMDB не принял ключ»** — проверьте `TMDB_TOKEN` и сделайте Redeploy.
- **Комнаты не сохраняются между заходами** — база не подключена к проекту: проверьте шаг 3 и сделайте Redeploy.
- **У друга сайт не открывается или открывается медленно** — адреса `*.vercel.app` доступны не у всех провайдеров. Помогает свой домен: **Settings → Domains**.

## Атрибуция

Данные о фильмах и постеры предоставляет [TMDB](https://www.themoviedb.org). Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB.
